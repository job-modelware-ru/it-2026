# Пример Redis: кэш месячной сводки

Пример написан для доклада. Он показывает чтение из кэша и БД, обновление версии результата, TTL и возврат к БД при недоступном Redis.

**Проверено 19.10.2026:** Python 3.12.14, Redis 8.10.2, redis-py 6.4.0. Сервер Redis был запущен локально без persistence. Все 9 тестовых методов прошли.

## Что находится в папке

- `demo.py` — исходные данные, расчёт, кэш и демонстрационный сценарий.
- `test_demo.py` — интеграционные проверки с настоящим Redis.
- `requirements.txt` — закреплённая версия клиента.
- `expected-output.txt` — сохранённый вывод выполненного примера.
- `commands.txt` — отдельные команды для redis-cli.

## 1. Запуск Redis

Запуск локального сервера через Docker:

```bash
docker run --rm --name yudin-redis-demo -p 127.0.0.1:6379:6379 redis:8.10.2 redis-server --save "" --appendonly no
```

Команда оставляет сервер в первом терминале. Остановка — Ctrl+C там же. Порт опубликован только на локальном интерфейсе. Если 6379 занят, можно указать свободный порт, например `127.0.0.1:6380:6379`, и передать Python адрес `redis://127.0.0.1:6380/0`.

Можно использовать уже установленный локальный Redis. Установка Docker не обязательна; альтернативы описаны в [официальном руководстве](https://redis.io/docs/latest/operate/oss_and_stack/install/).

## 2. Python-окружение

Команды выполняются во втором терминале из папки `src`.

macOS / Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python demo.py
```

Windows PowerShell, без обязательной активации окружения:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe demo.py
```

Другой адрес Redis:

```bash
python demo.py --redis-url redis://127.0.0.1:6380/0
```

## Последовательность выполнения

1. Первый запрос: DB, сумма 720.00.
2. Повтор: CACHE, сумма 720.00.
3. После добавления 80.00: DB, сумма 800.00.
4. Повтор: CACHE, сумма 800.00.
5. При недоступном соединении Redis: DB, сумма 800.00.

Последний шаг использует зарезервированный локальный порт без сервера. Он не выключает работающий Redis. Пример создаёт уникальный префикс ключей и удаляет только собственные ключи при завершении. FLUSHDB и FLUSHALL не вызываются.

## Проверки

```bash
python -m unittest -v test_demo.py
```

Для другого адреса задаётся переменная REDIS_URL.

macOS / Linux:

```bash
REDIS_URL=redis://127.0.0.1:6380/0 python -m unittest -v test_demo.py
```

PowerShell:

```powershell
$env:REDIS_URL = "redis://127.0.0.1:6380/0"
.\.venv\Scripts\python.exe -m unittest -v test_demo.py
```

## Границы примера

SQLite хранится в памяти процесса и заново заполняется при каждом запуске. Суммы представлены целыми копейками, чтобы исключить ошибки бинарного float. Пример выполняется в командной строке и демонстрирует механизм кэширования.

Счётчик `aggregate_queries` учитывает только агрегирующие запросы. Чтение ревизии не входит в этот счётчик. Сохранённый результат запуска приведён в `expected-output.txt`.
